# 尤里卡 (Eureka) · 桌面语音陪伴桌宠

一只住在桌面角落的 Live2D 桌宠：喊她的名字就能说话，会看着你的鼠标、跟着声音动嘴巴、被戳了会有反应。
她记得你说过的事，会追问你的计划、陪你专注、提醒你休息；她也有自己的日程和心情，你们的关系会随着相处慢慢变近。

> 当前版本见 `version.py`，每一版改了什么见 [CHANGELOG.md](CHANGELOG.md)。

## 安装

需要 Windows 10/11、Python 3.11、麦克风和音箱/耳机。

```bash
pip install -r requirements.txt
```

1. **准备一个阿里云百炼 API Key**：在 [百炼控制台](https://bailian.console.aliyun.com) 的「API-KEY 管理」里创建。她的脑子、眼睛和声音都用千问，一个 Key 就够。百炼按用量收费，见下面的「费用」
2. **放入 Live2D 模型**：程序**不附带任何模型**。把你有权使用的模型文件夹 (里面有 `xxx.model3.json`) 放进 `live2d_resources/`，或者之后在引导/设置里直接选 `.model3.json` 文件
3. **启动**：双击 `启动尤里卡.bat`。第一次打开会出现引导，按步骤填 Key、选隐私选项、选形象，点「开始」后她会自动重启

| 启动方式 | 说明 |
|---|---|
| `启动尤里卡.bat` | 日常使用，不显示命令行窗口，运行日志写在 `eureka.log` (超过 5MB 自动轮换) |
| `调试启动.bat` | 保留命令行窗口，出错时能直接看到报错 |

同时只能开一个；想开机就见到她，在 右键 → 系统配置 → 外观与角色 里勾「开机时自动启动」。

唤醒词和语音识别模型第一次用到时会自动下载到 `models/` (几十到几百 MB，需要能访问 GitHub / HuggingFace)；也可以提前运行 `python download_model.py` 一次下好。

## 怎么跟她玩

- **说话**：喊“尤里卡”或“你好尤里卡”唤醒，或者双击她；不方便说话时右键 →「打字跟她说」
- **连续聊天**：唤醒后进入实时语音对话 (千问 Omni)，可以连着说好几句不用再喊名字，她说完后 5 秒没人接话就回到待机；她说话时双击可以打断，戴耳机时可在右键菜单开「允许插话打断」
- **脚边的 ✦ 按钮**：所有功能一览，点一下就能用
- **左键拖动**：把她挪到任意位置，下次启动会记住
- **点头**：摸头；**点身体**：戳她，都会换表情、冒一句话
- **右键菜单 / 托盘图标**：免打扰、观察开关、置顶、藏起来、日志、系统配置、注册成员、退出

## 她能做什么

| 能力 | 说明 |
|---|---|
| 聊天 | 阳光开朗的人设 (可在角色设定里改)，回复边生成边说，表情由大模型自己挑 |
| 记忆 | 长期记忆：每轮聊完在后台提炼关于你的事实，和旧记忆比对后新增/更新/删除；短期记忆：最近 10 轮对话重启也记得，更早的自动压缩成摘要。都存在本机 |
| 声纹识别 | 听出是哪位成员在说话，自动切换档案 |
| 主动陪伴 | 聊天提到的计划 (“明天面试”) 当天打气、过后问结果；早安、离开回来说“你回来啦”、深夜提醒睡觉；生日祝福、每日早报、提醒摸鱼/熬夜 |
| 她自己的生活 | 每天有自己的日程，心情和精力会变；有固定的喜好和口头禅；偶尔主动分享她在忙什么 |
| 关系会成长 | 认识天数和纪念日；聊天、摸头、一起专注、完成任务都会让你们更亲近，越亲近说话越放松 |
| 今日任务 | 说“今天要写周报、改 bug”就记成清单，“周报写完了”打勾；下午提醒还剩的，傍晚收工回顾 |
| 工作统计 | 后台每 5 秒看一眼前台程序和窗口标题，按写代码/办公/视频/游戏等归类记时长；不截屏 (可在隐私设置关掉) |
| 陪你专注 | 说“陪我学习 25 分钟”：脚下显示倒计时，期间不打扰，结束提醒休息 |
| 不打扰 | 右键「免打扰」；全屏 (游戏/视频/开会) 时自动安静；两次主动开口至少隔 20 分钟 |
| 音乐 / B站 | 放歌；B站搜视频、看UP主更新、热门榜 |
| 电脑小事 | 打开软件 (`apps.json`)、调音量、打开浏览器搜索、倒计时提醒、闪念胶囊 (记到桌面 `memo.txt`) |
| 信息 | 查天气、联网搜索后总结、看屏幕 (你让她看时才截图，分析完立即删除；可在隐私设置关掉) |

出问题时 (Key 不对、欠费、断网、麦克风被占用) 她会冒一个气泡用人话告诉你怎么回事、去哪里改。

## 隐私

右键 → 系统配置 → **隐私** 可以随时调整，也能一键打开数据文件夹。

- **只存在你电脑上**：记忆库、聊天记录、任务清单、电脑使用统计、心情和关系、声纹、API Key (`.env`)
- **会发到阿里云百炼**：你说的话和她的回复 (用来思考和说话)、实时语音的音频、你主动让她看的屏幕截图
- **不会做**：不会偷偷截屏、不会上传你的文件、不会把数据发给百炼以外的地方 (QQ 机器人默认关闭)

想彻底清掉她的记忆，退出程序后删除 `memory.json`、`chat_history.json`、`eureka_memory_db/` 等文件即可 (都在 `.gitignore` 里列出)。

## 费用

百炼按用量计费，主要花在实时语音 (按音频时长) 和聊天 (按 token)。
脚边 ✦ →「今天干了啥」里能看到当天的用量；实时语音当天超过设定分钟数 (默认 60，设置 → 账号与模型 → 高级) 她会提醒一次。具体价格以百炼控制台为准。

## 换成你自己的角色

名字、人设、她自己的喜好与日程、唤醒词、用哪个 Live2D 模型都在 `character.json` (第一次启动自动生成) 里，
右键 → 系统配置 → 外观与角色 →「打开角色设定文件」。人设里 `{me}` 是她的名字，`{user}` 是你的名字。
如果你的模型表情名和默认的不一样，在 `expression_map` 里把 开心/害羞/生气… 对应到模型里的表情名。
想把窗口和托盘图标换成角色头像，把它存成 `assets/icon_custom.ico` 就行 (不会被提交)。

## 手机 QQ 上找她 (预留，默认关闭)

> 代码已经写好，但还没在真实环境里调通，目前默认不启动。要试的话在 `.env` 里加 `QQ_BOT_ENABLED=true`，再按下面的步骤配置。

走 QQ 开放平台的官方机器人接口；家里电脑不需要公网 IP。电脑开着、她在运行时才能回你。

1. 打开 [QQ 开放平台](https://q.qq.com)，完成个人开发者认证，创建一个机器人
2. 在机器人的开发设置里拿到 **AppID** 和 **AppSecret**，填进 `.env` 的 `QQ_BOT_APPID` / `QQ_BOT_SECRET`
3. 把你家的**公网 IP** 加进 IP 白名单 (开着代理的话，查**不走代理**的那个 IP)
4. 事件订阅勾选 **单聊消息 `C2C_MESSAGE_CREATE`**
5. 机器人没上线前只有沙箱成员能用：把自己的 QQ 加进沙箱，用手机 QQ 添加机器人
6. 启动后用手机 QQ 给机器人发一条消息，她会回你一个**身份码**；把 `身份码:你的名字` 填进 `QQ_ALLOWED_USERS`，重启

QQ 上只开放任务清单、记事、备忘、天气、联网搜索这些不用碰电脑的功能；QQ 规定只能在你发消息后 60 分钟内回复，所以她不会在 QQ 上主动找你。

## 开发

```bash
pip install -r requirements.txt pytest
python -m pytest tests
```

测试全部离线运行，不需要 Key、麦克风或模型。软件路径表在 `apps.json` (第一次运行从 `apps.example.json` 复制)。

| 文件 | 作用 |
|---|---|
| `gui_main.py` | 桌宠窗口、右键菜单、托盘、设置窗口 (入口) |
| `setup_ui.py` | 首次启动引导、账号与模型页、隐私页 |
| `theme.py` | 界面主题：配色、字体、全局样式 |
| `web_face.html` | Live2D 渲染：表情、嘴型、视线、待机动作 |
| `character.py` | 角色设定 (`character.json`)：名字、人设、唤醒词、模型、表情对应 |
| `main.py` | 主循环：唤醒 → 录音 → 识别 → 思考 → 执行工具 → 说话 |
| `events.py` | 后台到界面的事件通道 |
| `ai_brain.py` | 调用大模型：流式对话、工具调用、看图、主动台词 |
| `prompts.py` / `tools.py` | 提示词 / 她能用的工具定义 |
| `realtime.py` | 千问 Omni 实时语音对话 |
| `tts.py` | 平时说话：千问 Omni 朗读 (和实时对话同一音色) |
| `transcriber.py` / `recorder.py` / `wakeword.py` / `voiceprint.py` | 语音识别 / 录音 / 唤醒词 (sherpa-onnx) / 声纹 |
| `skills.py` | 各种技能的具体实现 |
| `memory_store.py` | 长期记忆：提炼事实、比对旧记忆、增/改/删，本地 ChromaDB |
| `companion.py` / `inner_life.py` / `relationship.py` | 主动陪伴 / 她自己的生活 / 你们的关系 |
| `tasks.py` / `activity.py` / `observer.py` | 今日任务 / 工作统计 / 根据统计判断要不要提醒 |
| `notify.py` / `usage.py` | 友好出错提示 / 用量统计与提醒 |
| `autostart.py` / `version.py` | 开机自启 / 版本号 |
| `qq_bot.py` | QQ 官方机器人 (预留，默认关闭) |
